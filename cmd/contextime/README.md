# Eternally · Windows 11 x64

双击项目根目录的 `Install-ContextIME.cmd` 安装独立 TSF 前端与 MyGo 后端。安装后通过 `Win + Space` 切到「Eternally」。无需墨奇、小狼毫或 WebView2。

- 中文输入 `niha` 或 `nihao`，可以选择「你好」。空格、数字键、回车和鼠标点击都可以选词。
- 普通中文可以直接选英文：输入常见英文词 `shift` 时，英文排在首位，同时保留中文候选；`nihao` 仍优先「你好」，也提供原样字母候选。输入 `Windows` 会保留大小写，空格或鼠标选中即可上屏，保持中文状态。
- 候选超过五个时，按 `↓` 或点右侧箭头展开，每屏最多显示四行、二十个候选。鼠标滚轮和 `Page Up`、`Page Down` 可以翻组。设置还支持用 `[`、`]` 或 `-`、`=` 翻组。悬停可查看被截断的长候选，点击即可选词。
- 默认开启翻译。候选窗依次显示原文、候选词和译文。用空格、数字键或鼠标逐词选入原文。写完后按回车提交整段译文。有待选拼音时，回车先选词。第三行可复制或手动朗读当前译文。也可在托盘菜单复制本次运行中最近的一条译文，或在设置中绑定快捷键。
- 按 `Ctrl + F8` 切换普通输入和翻译。普通模式直接输入当前语言，翻译模式先组成原文、预览译文，再按回车上屏。切回普通模式时，恢复上次所选的输入语言；快捷键可在设置中调整。
- Shift 只在普通模式内切换当前翻译方向的两种语言。例如「中文 → 日语」切换中文／日语，「英语 → 日语」切换英语／日语。在翻译模式下，单独短按 Shift 不切换语言或模式。普通中文选完最后一段拼音时直接上屏中文。
- 按 `Ctrl + F9` 轮换已勾选的常用目标语言。右键 Windows 系统托盘中的「Eternally」图标，选择「Eternally 设置」。在「翻译」中选择输入语言和目标语言，例如「英语 → 中文」「中文 → 日语」；点击「交换语言」即可反转方向，保存后生效。普通模式的语言选项跟随这组语言，输入和目标语言及普通模式所选语言会随后台重启保留。
- 中文使用拼音候选，日语使用罗马字转平假名、片假名；系统安装日语转换支持时，还可提供汉字候选。普通模式下选词直接输入，翻译模式下选入原文草稿，原文完成后按回车提交译文。
- 英语等拉丁字母语言直接输入，翻译模式下字母、空格、大小写和标点进入原文草稿，方向键移动光标，退格和 Delete 可编辑，回车提交整段译文。`Ctrl + V` 可将其他文字粘贴进原文翻译；其他复杂文字尚无内置专用组字引擎。「自动检测」由在线服务识别原文语言，此时普通模式的切换项为英语和目标语言。
- 标点自动跟随输入语言：普通模式使用当前所选语言，翻译模式使用原文语言。英语使用 ASCII 标点，中文使用 `，。！？` 等中文标点，日语使用 `、。！？` 和 `「」` 等日语符号。网址、邮箱和原样输入的路径、代码保留键盘符号。
- 输入 `v1` 到 `v9` 打开符号候选，分别对应标点、序号、数学与单位、平假名、片假名、希腊与拉丁字母、俄文字母、拼音与注音、制表符。用方向键选中后按空格或回车确认，也可以在移动高亮后用数字键选。
- 在 `v` 后连续输入多位数字、小数或日期可查看转换候选。例如 `v008` 可以选「零零八」，`v12.5` 可以选「一二点五」，`v2024.2.29` 可以选「2024年2月29日」或「2024-02-29」。
- 本地候选支持全拼、简拼、混合拼音和整句组词。`nhb` 可选「那好吧」，`bjdaxue` 可选「北京大学」，`woxiangqubeijing` 可一次选入「我想去北京」。常见拼写错误会自动给出修正候选，模糊音可在设置中开启。
- 输入 `https:`、`www.` 或像 `name@` 这样的邮件开头可继续原样输入，按空格结束该片段。邮箱用户名含数字、点号或其他符号时，先按 `Shift + 空格`。输入文件路径、代码时也可用这个快捷键，输完再按一次即可接着打拼音。翻译时会保留原样片段的大小写和标点。
- 翻译模式在第三行显示译文或请求状态。请求失败、断网或超时后可按回车重试，当前原文保留。修改原文或切换语言会取消之前的请求。同一输入语言、目标语言和翻译引擎的近期结果可在本次运行中复用，关闭后台后清空。
- 默认使用微软 Edge 在线翻译，可选择不同语言之间的翻译方向。在「翻译」设置中可下载约 122 MB 的离线中译英模型，该模型仅支持「中文 → 英语」，不会覆盖已保存的在线语言对。下载后选择离线引擎并保存即可。只有勾选允许在线回退时，离线模型不可用才会改用在线服务。
- 确认上屏后会记录所选字词。相同拼音下，使用次数多的候选会靠前，次数相同则优先最近用过的候选。设置中的「词库」可置顶、删除学习记录、备份及恢复和编辑自定义短语。词频保存在本机的 `%APPDATA%\ContextIME\words.json`，断网时也能学习和排序。

用 `native-tsf/Build.ps1 -Zig <zig.exe 路径>` 同时构建 Go 后端和独立 TSF DLL。Go 使用 `CGO_ENABLED=0`。Zig 单独编译 C 写的 Windows 接入层。

词库源自 [雾凇拼音](https://github.com/iDvel/rime-ice) 数据，从本机可用的白霜拼音所含字表和词表提取。筛选、排序后将词和拼音打包到 `words.tsv.gz`。许可见同目录的 `words-LICENSE`。

可选离线翻译模型由 Helsinki-NLP 训练，采用 CC BY 4.0 许可。下载模型包时一并获取 Windows x64 ONNX Runtime 及其许可文件。 [原模型](https://huggingface.co/Helsinki-NLP/opus-mt-zh-en) · [量化 ONNX 权重](https://huggingface.co/Xenova/opus-mt-zh-en) · [ONNX Runtime](https://github.com/microsoft/onnxruntime)

自定义短语也可在 `%APPDATA%\ContextIME\phrases.json` 中直接编辑。键是用小写字母组成的缩写，值是一组短语。保存后重新输入缩写，短语会排在候选栏前面。

```json
{
  "dz": ["请把文件发到这个地址", "收货地址"],
  "hy": ["会议改到明天下午三点"]
}
```

```powershell
$env:CGO_ENABLED = '0'
go build -trimpath -ldflags '-H=windowsgui' -o dist/ContextIME.exe ./cmd/contextime
```

直接打开 `dist/ContextIME.exe` 是交互演示。初始拼音为 `nihao`。第一次回车选「你好」，第二次回车显示「提交完成」。左右键切换候选，数字和空格选词。

## 旧版墨奇接入

`--moqi` 模式使用墨奇 1.0.5 的 Protobuf 帧协议。它不向 TSF 发送原生候选列表，MyGo 独立显示唯一候选窗。最终英文通过响应的 `commit_string` 交回 TSF。原生候选窗在目标应用中的焦点和光标位置由 Windows 窗口信息推断，应用未提供光标位置时临时使用鼠标位置。

旧版脚本在 `integration/moqi/Install.ps1`，用于维护原接入。新版独立安装会禁用旧版「语境输入」条目，保留墨奇自身的配置。
